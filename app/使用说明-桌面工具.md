# TVBox 配置工具 · 使用说明

一个免安装的 Windows 桌面程序（`TVBox配置工具.exe`，约 12MB），把「开服务、看地址、复检、更新配置」四件事放在一个窗口里。

## 启动

双击 `TVBox配置工具.exe`。

- 程序会自动找到旁边的 `output` 配置目录（放在 `tvbox` 文件夹里即可，拷到别的位置就点右上角「更改目录」重新指定一次）。
- **首次运行会弹 Windows 防火墙提示，勾选「专用网络」并点「允许访问」**，否则电视连不上。
- 默认勾选「启动程序时自动开启服务」，设置会记住。

## 界面分区

| 区域 | 功能 |
|---|---|
| ① 服务控制 | 启动/停止 HTTP 分发服务；端口默认 9978；下方实时显示每个网卡的配置地址，可一键复制、可在浏览器打开 |
| ② 当前配置 | 下拉选择要用的配置文件（默认 `tvbox-osc-fixed.json`），并显示站点/直播/解析数量；地址栏会跟着这个选择变 |
| ③ 复检 / 更新 | 见下 |

## 复检会做什么

- **配置体检**：按 TVBox 的数据模型检查字段类型、重复 key（防「配置失败」）
- **spider jar**：本地副本存在性、MD5 与声明比对、dex 内 spider 类计数
- **采集源**（type 0/1）：逐站真实搜索「庆余年」，三级参数回退
- **spider 站点**（type 3）：校验 `csp_类名` 是否真的存在于 jar 的 dex 里
- **直播**：精选 53 台逐台实测可播性；其余直播源抓清单后抽样 6 台
- **解析器**：用复检时拿到的真实播放地址逐个测

spider 站点的内容源必须在电视端才能最终确认，桌面端做到「类存在 + jar 配套」这一步为止。

## 更新配置

复检完成后，若存在失效条目，「应用结果并更新配置」按钮会亮起：

- 点击后列出将剔除的数量，确认后写回当前配置文件
- **原文件自动备份到 `output/backup/配置名.时间戳.bak`**，直接改回文件名即可回滚
- 本地 `live.txt` 会同步裁剪掉失效频道
- 更新后在 TVBox 里「清空缓存」重新加载即可生效

## 常见问题

- **提示端口被占用**：之前遗留的 `serve.py` 或另一个实例还开着，换端口（如 9979）或到任务管理器结束旧进程。
- **电视连不上**：确认同一 WiFi、防火墙已放行、地址里的 IP 和电视所在网段一致（程序会列出所有网卡地址）。
- **换了 WiFi / 路由器重拨后失效**：电脑 IP 变了，重启一下程序即可（地址自动刷新）；想固定 IP 就在路由器里做 DHCP 绑定。
- **想彻底不依赖电脑**：把 `output` 里的 `tvbox-config.json`、`spider.jar`、`live.txt` 拷到电视 `/sdcard/TVBox/`，配置地址填 `clan://localhost/TVBox/tvbox-config.json`。

## 开发者

- 源码：`app/TVBoxTool.py`（纯标准库 tkinter）
- 重新打包：双击 `app/build_exe.bat`
- 命令行自检（不弹窗）：`python TVBoxTool.py --cli`（加 `--quick` 抽样）
